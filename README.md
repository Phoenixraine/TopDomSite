# ТОП ДОМ — лендинг выставки домов в КП «Рига Лайф»

Статичный сайт без сборки: `index.html` + `assets/`.

## Запуск локально
```
npx serve .
```

## Деплой на Vercel
1. vercel.com → Add New → Project → импортировать этот репозиторий.
2. Framework Preset: **Other**, Build Command пустой, Output Directory `.`.
3. Deploy. Каждый push в ветку обновит сайт.

## Что поменять, когда появится контент
- Все черновые тексты помечены атрибутом `data-placeholder` в `index.html` — поиск по нему покажет, что заменить.
- Дата события для обратного отсчёта: `EVENT_START` в `assets/js/main.js`.
- Отправка формы: блок `TODO` в `assets/js/main.js` (сейчас форма только показывает «билет»).
- Изображения: `assets/img/*.webp` (большие) и `*-sm.webp` (до 1000 px). Сейчас это 3D-рендеры-заглушки;
  замените на фото посёлка/домов с теми же именами файлов, для «вырезанных» домов нужен PNG/WebP с прозрачным фоном.

## Стек
GSAP + ScrollTrigger (анимации), Lenis (плавный скролл на десктопе). Библиотеки лежат в `assets/vendor/`.
Ховер-эффекты включаются только на устройствах с мышью (`@media (hover: hover)`), на тач-экранах — отклик на нажатие.
